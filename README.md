# Musor Drop — 10 сайтов

Готовые статические сайты (HTML/CSS/JS) лежат в папках `site-11` … `site-20`.

| Папка | Что это | Лента дропа |
|---|---|---|
| `site-11` | Копия musordrop.net (индиго) | нет |
| `site-12` | Копия musordrop.net (пурпурный) | нет |
| `site-13` | Копия в духе 11–12 (индиго, ключ «мусор дроп») | нет |
| `site-14` | Копия в духе 11–12 (пурпурный, ключ «Musor Drop / musordrop») | нет |
| `site-15` | Копия в духе 11–12 (орхидейный, ключ «апгрейд / дроп скинов») | нет |
| `site-16` | Каталог кейсов (Мусорная коллекция, Оружие, Культ Моды) | есть |
| `site-17` | Журнал (статьи, промокоды, словарь) | есть |
| `site-18` | Калькулятор бюджета (Мусорный минимум, VIP Color) | есть |
| `site-19` | Вики-справочник | есть |
| `site-20` | Справочный центр: вопрос — отдельная страница | есть |

У каждого сайта свои картинки: каталоги показывают разные коллекции кейсов, скины — свои наборы в `_shared/skinsN/`.
Три сайта (прайс-лист, подборки, инструкции) убраны в архив: исходники в `build/archive/`, скины в `_shared/_archive/`. Чтобы вернуть — перенести `vN.mjs` в `build/sites/`, `vN.css` в `build/css/`, скины обратно в `_shared/` и указать `out`.

## Как посмотреть

Ссылки на сайтах абсолютные (`/cases/` и т.п.), поэтому открывать `index.html` двойным кликом нельзя — нужен локальный сервер. Из корня репозитория:

```
python -m http.server 8111 -d site-11
python -m http.server 8112 -d site-12
…
python -m http.server 8120 -d site-20
```

Затем открыть http://localhost:8111/ (8112 … 8120).

## Как пересобрать

Исходники — в `build/` (тексты, CSS, шаблоны), ассеты — в `_shared/`. Нужен Node.js:

```
node build/build.mjs          # все сайты
node build/build.mjs site-16  # один сайт
```

## Превью по ссылке (GitHub Pages)
