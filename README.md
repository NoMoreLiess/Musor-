# Musor Drop — 4 сайта

Готовые статические сайты (HTML/CSS/JS) лежат в папках `site-1` … `site-4`.

| Папка | Что это |
|---|---|
| `site-1` | Сайт-копия 1 (индиго-фиолетовый) |
| `site-2` | Сайт-копия 2 (пурпурный) |
| `site-3` | Каталог кейсов (100 кейсов, коллекции) |
| `site-4` | Журнал (статьи, промокоды, словарь) |

## Как посмотреть

Ссылки на сайтах абсолютные (`/cases/` и т.п.), поэтому открывать `index.html` двойным кликом нельзя — нужен локальный сервер. Из корня репозитория:

```
python -m http.server 8101 -d site-1
python -m http.server 8102 -d site-2
python -m http.server 8103 -d site-3
python -m http.server 8104 -d site-4
```

Затем открыть http://localhost:8101/ (8102, 8103, 8104).

## Как пересобрать

Исходники — в `build/` (тексты, CSS, шаблоны), ассеты — в `_shared/`. Нужен Node.js:

```
node build/build.mjs          # все сайты
node build/build.mjs site-3   # один сайт
```
