Что такое provably fair и как пересчитать свой раунд

Хеш, server seed и client seed — объясняем, почему результат кейса или апгрейда нельзя подменить задним числом.

Provably fair — это способ доказать, что результат раунда не подкручен. Проверить его может любой игрок.

Из чего складывается результат

  • Server seed — секретная строка платформы, её хеш публикуется заранее.
  • Client seed — строка, которую можете задать вы.
  • Nonce — номер раунда.

Почему подмена невозможна

Хеш server seed опубликован до раунда. Если бы seed поменяли после, хеш бы не совпал — и это сразу стало бы заметно.

Как проверить самому

После раунда server seed раскрывается. Возьмите его, свой client seed и nonce, посчитайте результат по опубликованному алгоритму и сравните с тем, что выпало.
