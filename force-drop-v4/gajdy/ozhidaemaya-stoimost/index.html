Ожидаемая стоимость (EV)

Ожидаемая стоимость (EV) — средняя цена дропа при бесконечно большом числе открытий одного кейса. Ключевая метрика для оценки реальной стоимости любого режима.

БрифингПерейти на Force DropВсе гайды

Формула

EV = Σ (вероятность предмета × цена предмета).

Модель: три предмета с вероятностями 70%, 25%, 5% и ценами €0.50, €2, €20.

EV = 0.70 × 0.50 + 0.25 × 2 + 0.05 × 20 = 0.35 + 0.50 + 1.00 = €1.85.

Интерпретация

При цене кейса €2.20 одно открытие в среднем возвращает €1.85 — 84%. Остальные 16% — доход сервиса. Отдельное открытие может дать €20, но с ростом числа открытий средний результат приближается к €1.85.

Значения модельные: Force Drop не публикует вероятности, поэтому реальный EV конкретного кейса рассчитать нельзя.

EV по режимам

  • Апгрейд: EV = шанс × цена цели; при шансе 1/множитель EV равен ставке, с комиссией — ниже. См. апгрейд.
  • Контракт: EV — средняя цена результата при заданной сумме набора; она ниже суммы.
  • Сражение: EV равен EV кейсов, разброс — выше.

Выводы

  1. Стратегия не поднимает EV выше цены — она влияет только на разброс.
  2. Чем больше открытий, тем ближе итог к EV, то есть к потере комиссии.
  3. Корректная модель поведения — бюджет на развлечение, заданный заранее.
