Под капотом

Как считается результат

Результат раунда — функция от server seed, client seed и nonce. Хеш server seed виден до игры.

После смены пары сидов server seed раскрывается, и любой раунд можно пересчитать.

fairness.log
server_hash 3e91a0c7…f42b
client_seed my-own-seed
nonce       27
result      0.7316
✓ хеш совпал

Сколько времени занимает

Вход — около минуты. Открытие кейса или раунд апгрейда — секунда. Вывод — обычно несколько минут, если предмет есть у бота.
